## On "self-updating documentation"

Mintlify's pitch is *"the knowledge platform built for agents"* — docs that
agents can read, and an agent that keeps docs updated via pull requests.
Where we stand:

- **Agents reading us**: built. Plain MDX in git, role-aware `llms.txt` and
  `llms-full.txt`, every page at `/<slug>.md`, an
  [MCP server](/platform/ai/agent-access), token auth for agents, and an
  embedded [Ask AI assistant](/platform/ai/assistant).
- **Self-updating**: the API reference regenerates from the OpenAPI spec on
  every request, and the [docs agent workflow](/platform/ai/docs-agent) runs
  Claude Code on each merge to propose doc-sync PRs for prose. Humans still
  approve every change — by design.

<Note>
  The one honest caveat: the CI workflows (docs agent, preview deployments)
  ship configured but exercise only in GitHub Actions with the repository
  secrets set — validate them on the first real merge.
</Note>
