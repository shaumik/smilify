<Update label="July 2026" description="v1.0.0">
  ## Initial release 🎉

  The internal docs platform ships with full Mintlify feature parity:

  - MDX authoring with the complete component library
  - `docs.json` navigation with tabs, groups, and role-gated sections
  - Session authentication on every route with admin/member roles
  - ⌘K full-text search with server-side role filtering
  - OpenAPI-generated API reference with an interactive playground
  - Dark mode, `llms.txt`, page feedback, and prev/next navigation
</Update>
