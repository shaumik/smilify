The pages in this tab are **generated from `openapi/openapi.json`**. Each
endpoint page includes parameter and response documentation, code samples in
three languages, and an interactive **Try it** playground that sends real
requests to the API.

## Base URL

```text
/api/v1
```

The playground calls the live sandbox environment, seeded with sample data
that resets on restart.

## Authentication

All endpoints require a bearer key:

```bash
curl "/api/v1/smiles" \
  -H "Authorization: Bearer $SMILIFY_API_KEY"
```

<Tip>
  The playground is pre-provisioned with this workspace's sandbox key, so you
  can hit **Send** on any endpoint immediately. Clear the key and send to see
  the `401` error shape.
</Tip>

## Adding endpoints

An API page is just frontmatter — no body required:

```mdx title="content/api-reference/smiles/list.mdx"
---
title: List smiles
openapi: GET /smiles
---
```

Update the OpenAPI spec, add a page with the `openapi` field, list it in
`docs.json`, and the docs, samples, and playground are generated for you.
