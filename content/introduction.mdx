**Smilify Docs** is our self-hosted documentation platform — a fully internal
replacement for Mintlify. Everything runs on our own infrastructure, behind our
own authentication, with no third-party service in the loop.

<Note>
  This site is access-controlled. Every page, search query, and API playground
  request requires a signed-in session. Sign-in state is carried in an
  HTTP-only session cookie verified by middleware on every request.
</Note>

## How it works

The platform is a Next.js application:

- **Content** lives in `content/**/*.mdx` — plain files, versioned in git.
- **Navigation** is defined in `docs.json`, using the same schema shape as
  Mintlify's `docs.json`, so existing Mintlify content migrates with almost no
  changes.
- **Auth** is enforced in `middleware.ts`: no session, no page.
- **API reference** pages are generated from `openapi/openapi.json`.
