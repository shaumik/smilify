## Checklist

<Steps>
  <Step title="Set the session secret">
    ```bash
    export SESSION_SECRET="$(openssl rand -hex 32)"
    ```

    <Danger>
      Never deploy with the development fallback secret. Anyone who reads the
      source could forge admin sessions.
    </Danger>
  </Step>
  <Step title="Build and run">
    ```bash
    npm run build
    npm start   # serves on :3000
    ```
  </Step>
  <Step title="Terminate TLS">
    Put the app behind the standard internal nginx/ALB with HTTPS. The session
    cookie is marked `Secure` in production builds.
  </Step>
  <Step title="Wire up real identity">
    Replace the demo credential store with our IdP (see
    [Authentication](/authentication)) before opening access beyond the pilot
    group.
  </Step>
</Steps>

## Operational notes

- The app is stateless except for `data/feedback.jsonl`; mount a volume or
  ship feedback to analytics if you care about persistence.
- Content deploys are just git deploys — CI builds the image on merge to main.
